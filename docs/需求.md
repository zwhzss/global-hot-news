开发一套获得全世界热点咨询的系统，本地个人使用，非商用。

二、合规性
1、单纯事实性、时事新闻，只抓取时间、地点、人物、事件、事实摘要、标题、导语，不抓取以下内容：深度报道、评论、特写、新闻图片、原创稿件，这些内容通过外部链接显示。
2、严格按照平台的 robots.txt规定抓取该平台数据
3、绝对不能做：
- 绕过验证码、登录、反爬、防火墙、付费墙去抓取内容（突破技术保护措施）
- 高频并发请求，打垮对方服务器（造成网站拒绝服务，涉嫌破坏计算机信息系统）
- 抓取个人隐私信息（人名、手机号、邮箱等）
4、温和爬虫：低频率、几个线程数、遵守 robots，仅抓取公开可访问的公开资讯，不突破反爬。
5、不存储、浏览、处理违法违规有害信息**（分裂、煽动、暴力、虚假重大谣言等）
6、在系统内增加简单过滤：识别、拦截、不保存违法有害内容；不留存违规内容在本地硬盘。
7、存储策略：**只存标题 + 摘要，不存全文、原图**；设置自动过期清理旧数据。
8、严格限制：**绝不把抓取到的资讯对外分享、上传、发布、给别人访问，绝对不商用**。
9、禁止翻墙访问境外网站获取资讯，使用国内合规国际互联网通道。
10、本地增加内容过滤，发现违规内容自动丢弃，不落地保存。
