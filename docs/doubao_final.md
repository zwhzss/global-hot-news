# 全球热点资讯桌面系统｜最终版架构设计文档

> 
> 依据原始需求`需求.md`，综合`deepseek.md`、`doubao.md`、`qwen.md`三份架构方案优势进行融合；
> 项目定位：**Windows 单机桌面应用，仅限个人本地非商用学习研究；全部数据保存在本机，不上云；严格落实全部合规约束**。
> 技术栈：Go (Gin+GORM)、SQLite3、Angular、Wails v2、NSIS。

## 设计取舍说明（融合三份方案优点）

1. 吸收 **deepseek.md**：插件化采集器、统一分类树 + 多视图、SimHash/Fingerprint 指纹去重、独立`filter_logs`不存储违规原文、本地仅监听`127.0.0.1`增加随机 token 防护、完整项目目录结构。
2. 吸收 **qwen.md**：五层分层架构、横切合规 / 可观测能力、适配器模式、完整端到端数据流、板块去重归属规则、非功能性指标（性能、可靠性、可维护）。
3. 吸收 **doubao.md**：Wails Bindings 进程内调用备选方案、详细表字段、业务流程图、风险约束清单。
4. 摒弃冗余重复：**不重复存储财经 / 经济重复内容，底层统一资讯池，前端仅做视图筛选；不重复采集；区分实体关联表，避免字段冗余**。
5. 严格对齐原始需求全部合规条款，合规作为横切强制组件，不是可选功能。

## 1 总体约束（来自原始需求，最高优先级）

1. 仅抓取**事实性时事新闻：标题、摘要、导语、时间、地点、人物、事件、外部源链接**；深度报道、评论、特写、图片、原创稿件**不抓取不落地，WebView 跳转外部阅读**。
2. 强制遵守`robots.txt`；禁止绕过验证码、登录、反爬、付费墙；温和采集低并发（默认 1‑3 协程）。
3. 禁止抓取个人隐私；命中违法有害内容直接丢弃，**违规内容绝不落地硬盘，日志仅记录哈希与原因码**。
4. 存储最小化：只存元数据；配置资讯 TTL 自动过期清理。
5. 软件**无对外分享、上传、发布能力，禁止商用；程序不实现翻墙，依赖本机合规网络**。
6. 部署形态：Windows 桌面 exe，数据库放置于`%APPDATA%/GlobalHotNews/global_hotnews.db`，升级安装不覆盖用户数据。

### 端到端完整数据流

> 
> 采集全链路，**过滤、去重在入库之前执行**

1. 调度器触发已激活数据源任务 → 2.Robots 强制校验不通过直接标记异常终止；3. 令牌桶限速 + 随机抖动延时；4. 插件适配器拉取公开源，仅提取事实元字段；5. 去重（URL 标准化 + SimHash 指纹）；6. 合规过滤组件拦截，违规直接丢弃，写入 filter_logs，**不保存违规文本**；7. 打分类 / 标签；8. 写入 articles；9. 定时 TTL 清理过期数据；10. 用户浏览行为埋点入库；11. 画像模块本地计算偏好权重；12. 前端通过视图筛选展示，原文 WebView 跳转外部链接。

## 3 后端模块详细设计

### 3.1 插件化采集子系统

#### 数据源抽象接口

```
type IDataSource interface {
    TestConnect() (TestResult, error)   // 前端测试按钮调用，返回可用性+样例数据
    Fetch() ([]RawNewsItem, error)      // 采集输出标准化原始资讯元组
    GetRobotsAllow(url string) (bool, error) // robots规则校验
}
```

- 实现适配器：`RssAtomSource`、`OpenApiSource`、`HtmlListSource(选择器解析公开列表页)`
- `RawNewsItem`结构体字段：`Title`、`Summary`、`Lead`、`PublishTime`、`OriginUrl`、`Locations`、`Persons`、`Events`；**不含正文、图片二进制**。

#### 核心组件

1. **Robots 解析器**：采集前置强制校验；获取 robots 失败直接标记数据源异常，不执行抓取。
2. **RateLimit 限速器**：[golang.org/x/time/rate](https://golang.org/x/time/rate)令牌桶；全局最大协程、每个数据源独立间隔 + 随机抖动；遇到 403/429/5xx 执行退避，标记数据源异常。
3. **任务调度 Scheduler**：基于 cron 表达式，任务队列；未激活数据源不参与调度；采集完成回写数据源状态、错误信息。
4. **去重归一组件**：URL 规范化；资讯指纹 SimHash；同一事件多源聚合，主记录保存，其他来源存入关联，避免重复入库。

### 3.2 横切：合规过滤组件（入库必经拦截，强制不可绕过）

> 
> 原始需求强制约束；**命中违规直接丢弃，不落地任何违规文本**。

1. 支持**全局过滤规则 + 数据源绑定私有过滤规则**；关键词匹配可使用 AC 自动机提升性能。
2. 过滤动作：丢弃拦截；仅记录`filter_logs`，日志字段：source_id、rule_id、reason_code、content_hash、created_at；**不存储标题 / 摘要违规原文**。
3. 自动剥离隐私字段；不存储图片、评论、深度报道内容。
4. 定时 TTL 任务：按照系统配置保留天数清理过期`articles`，同时清理过期热榜快照、旧行为日志；可执行 SQLite VACUUM 优化文件体积。

### 3.3 数据源管理服务

- CRUD 数据源：名称、类型、URL、激活状态、cron 采集周期、请求间隔、绑定过滤规则 ID。
- 连通性测试功能；自动周期性检测数据源可用性，前端展示状态：正常 / 网络错误 /robots 禁止 / 限流 429 / 解析失败，附带错误信息。

### 3.4 资讯、分类与视图（重点：统一资讯池，多视图展示）

> 
> 解决原始需求 4‑8 板块重复内容规划：底层一份 articles 资讯池；**财经、军事、科技、政治、经济是前端筛选视图，不重复存储数据**。

1. 多级分类树`categories`：主分类 + 子分类，严格对齐需求文档全部子项。
2. 多对多关联表`article_categories`，一篇资讯可绑定多个分类标签。
3. 板块去重归属规则（严格遵循需求提示）
   - 军工芯片、新材料底层技术归属【科技】；军工企业财报股价归属【财经】；武器装备、防务政策归属【军事】。
   - 企业新产品技术发布归属【科技】；企业财报股价归属【财经】。
   - 宏观实体经济指标归入【经济】；证券、大宗商品、资管交易类归入【财经】。
   - 各类智库评论统一打对应领域二级标签。
4. 热榜聚合服务：读取已入库资讯，多源热榜归一打分 `score = (N‑rank+1)/N * source_weight * time_decay`；生成快照存入`hot_ranks`表。

### 3.5 关注管理服务

- 两种关注类型：**资讯、数据源**；存入`follows`表。
- 用户打开资讯页面埋点上报浏览行为：news_id、source_id、stay_ms、click_origin (是否打开 WebView) 写入`user_behaviors`。
- 阅读原文：前端 Wails WebView 打开`origin_url`外部链接，本地程序**不下载、不缓存网页正文图片**。

### 3.6 用户画像 & 个性化推荐服务

> 
> **全部本地内存 / 数据库计算，不上传任何行为数据；支持一键重置画像**。

1. `user_profile`保存各分类、数据源兴趣权重；权重计算因子：浏览次数、停留时长加权、关注加分、取消关注减分、旧行为时间衰减。
2. 推荐排序公式：`score = 分类匹配度 * 来源偏好 * 时效系数 − 已读惩罚`。
3. 冷启动策略：无行为时返回综合热榜数据。

### 3.7 系统配置服务

全局配置：爬虫全局并发、默认请求间隔、资讯 TTL 保留天数、全局过滤规则、日志级别；配置持久化`system_settings`。

## 5 前端 Angular 模块与页面规划

Angular 采用模块化 + 路由懒加载；共享组件：资讯卡片组件、WebView 容器组件、数据源状态提示组件。

页面清单：

1. **推荐页**：个性化推荐资讯列表；卡片展示标题、摘要、来源；点击唤起 WebView 打开外部链接。
2. **我的关注页**：Tab1 关注资讯；Tab2 关注数据源；支持关注 / 取消关注。
3. **热榜页**：本地聚合综合热榜，按热榜分数排序。
4. **分类视图页（底层共用 articles，前端筛选）**
   - 财经视图：子分类对齐需求 4.1‑4.9
   - 军事视图：子分类对齐需求 5.1‑5.7
   - 科技视图：子分类对齐需求 6.1‑6.10
   - 政治视图：子分类对齐需求 7.1‑7.5
   - 经济视图：子分类对齐需求 8.1‑8.7
   - 更多视图：社会民生、环境与自然灾害、文化体育、健康公共卫生
5. **数据源管理页面**：新增编辑删除、激活开关、【测试连通】按钮；列表展示可用性状态、报错信息；绑定过滤规则、配置采集参数。
6. **过滤规则管理页**：维护全局 / 私有黑名单关键词规则。
7. **系统设置页面**：爬虫全局参数、资讯保留 TTL 天数、重置画像、查看采集 / 过滤日志。

> 
> WebView 约束：仅加载外部 origin_url；前端不保存网页资源。

## 7 构建、编译、发布流程

1. 开发调试：`wails dev`；Go 后端 + Angular 前端联合调试。
2. 编译：`wails build`生成 Windows exe，前端静态资源内嵌到二进制。
3. NSIS 打包：执行 NSIS 脚本生成 Windows 安装包。
4. 部署行为：
   - 程序本体安装到用户选择安装目录；
   - SQLite 数据库、配置、日志全部写入`%APPDATA%\GlobalHotNews`；
   - 升级安装不会覆盖用户数据源配置、本地元数据；卸载可选择清除用户数据。

## 8 安全与合规清单（软件说明书必须包含）

1. 只抓取公开事实资讯；仅保存标题摘要导语元数据；原文图片通过外部 WebView 查看，本地不存储。
2. 强制 robots.txt 校验，温和低并发采集，禁止绕过验证码、登录、付费墙。
3. 不采集个人隐私信息；命中违法有害资讯直接丢弃，不落地存储。
4. 资讯设置 TTL 自动过期清理，控制本地存储风险。
5. 程序不提供任何对外分享、上传、发布能力，仅限个人非商用学习研究。
6. 程序无翻墙、代理实现，依赖本机网络，用户不得使用翻墙获取资讯源。
7. 本地 API 仅绑定 127.0.0.1，增加随机 token 防护本机其他程序越权访问。
8. 提示：内置关键词过滤能力有限，无法识别全部变体有害内容。

## 9 非功能性需求

1. **性能**：单机低资源占用；采集和 UI 渲染解耦；SQLite 满足个人量级。
2. **可靠性**：采集失败退避重试；数据源状态自检；违规数据绝不入库。
3. **可维护性**：适配器插件化，新增数据源只需要实现接口；分类配置驱动，便于调整子分类。
4. **可观测**：采集日志、过滤丢弃日志；前端直接展示数据源异常报错。

## 10 可选扩展（非 MVP 版本，后续迭代）

1. 数据源配置 JSON 导入导出；
2. SQLite‑FTS 本地全文检索（仅标题、摘要）；
3. 资讯元数据导出 CSV（仅标题、摘要、外部链接，**禁止导出原文**）；
4. 静默升级机制。
